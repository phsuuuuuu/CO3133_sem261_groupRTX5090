Problem statement

Fashion-MNIST 10-class image classification. Build an end-to-end training pipeline and evaluate baseline models (Linear Classifier and MLP).

Dataset description and EDA

  • Dataset: Fashion-MNIST
  • Splits: 54,000 train, 6,000 validation, 10,000 test (seed = 666).
  • Preprocessing: Mean and std calculated only on train set to avoid data leakage.

Methodology

  • Linear Classifier: Flatten(784) → Linear(784, 10) — 7,850 parameters.
  • MLP: Flatten(784) → Linear(784, 256) → ReLU → Dropout(0.2) → Linear(256, 10) — 203,530 parameters.
  • Loss & Optimizer: Cross-Entropy Loss, Adam (lr = 0.001).

Experimental setup

  • Hardware / Environment: Python 3.12, PyTorch 2.14, Scikit-learn.
  • Hyperparameters: batch_size = 200, epochs = 10, seed = 666.
  • Evaluation: Loss, Accuracy, Macro-F1, inference time on test set (10,000 images). Best checkpoint saved by validation Macro-F1.
