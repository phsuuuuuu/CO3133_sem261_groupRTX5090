Problem statement

Cityscapes 19-class urban semantic segmentation. Build an end-to-end training pipeline, enforce city-level partitioning to prevent spatial leakage, and evaluate baseline and modern models (U-Net and DeepLabV3-ResNet50).

Dataset description and EDA

  • Dataset: Cityscapes (19 classes, ignore index 255).
  • Splits: 2,481 train (14 cities), 494 validation (4 cities), 500 test (3 cities).
  • Preprocessing: Resized to 512×1024, random crop to 512×512 during training, random horizontal flip, and ImageNet normalization.

Methodology

  • U-Net (Baseline): 4 encoder stages (DoubleConv + MaxPool2d), bottleneck, 4 decoder stages (ConvTranspose2d + DoubleConv with skip connections) — 31,037,651 parameters.
  • DeepLabV3-ResNet50: ResNet-50 backbone pretrained on ImageNet-1K (frozen), Atrous Spatial Pyramid Pooling (ASPP) with dilation rates (6, 12, 18), 19-class classifier — 15,620,883 trainable parameters (39,631,059 total).
  • Loss & Optimizer: Cross-Entropy Loss (ignore_index = 255), AdamW (lr = 0.001).

Experimental setup

  • Hardware / Environment: Python 3.12, PyTorch 2.13, NVIDIA GeForce RTX 5070 Ti.
  • Hyperparameters: batch_size = 8, epochs = 10, seed = 666.
  • Evaluation: Loss, mIoU, Mean Dice, and Pixel Accuracy on validation split (494 images). Best checkpoint saved by validation mIoU.
