1. Problem and Task

The objective of this project is to perform semantic segmentation of urban street scenes. The model assigns one semantic class to every valid pixel in an input street image.

Input: an RGB image with original Cityscapes resolution 2048 × 1024 pixels.

Output: a pixel-wise segmentation mask containing one of 19 target semantic classes for each valid pixel.

The 19 evaluation classes are:

road, sidewalk, building, wall, fence, pole, traffic light, traffic sign, vegetation, terrain, sky, person, rider, car, truck, bus, train, motorcycle, and bicycle.

Pixels outside the 19 evaluation classes use the ignore value 255 and are excluded from training loss and evaluation.

2. Dataset Information

This project uses the Cityscapes Dataset, which contains high-resolution urban street-scene images together with dense pixel-level annotations.

Package Purpose Approx. Size
leftImg8bit_trainvaltest.zip RGB street-scene images 11 GB
gtFine_trainvaltest.zip Fine semantic segmentation annotations 241 MB

The complete Cityscapes fine dataset contains 5,000 images:

  • 2,975 official training images
  • 500 official validation images
  • 1,525 official test images

Ground-truth labels for the official 1,525 test images are withheld by Cityscapes. Therefore, they will not be used for quantitative local evaluation.

Official dataset: Cityscapes Dataset

3. Preliminary Exploratory Data Analysis

Pixel-level exploratory analysis was performed on the 2,975 images in the official Cityscapes training partition.

  • Total pixels: 6,239,027,200
  • Valid pixels belonging to the 19 target classes: 5,523,279,889
  • Ignored pixels: 715,747,311 (approximately 11.47%)

The dataset is highly imbalanced. Road, building, and vegetation together account for approximately 75.62% of all valid pixels.

Class Percentage of Valid Pixels
Road 36.87%
Building 22.82%
Vegetation 15.93%
Car 6.99%
Sidewalk 6.08%
Motorcycle 0.10%

Minority classes such as motorcycle, rider, train, bus, and truck are expected to be more difficult to segment. Boundary accuracy between adjacent objects is another important challenge.

4. Data Split and Leakage Prevention

Since the labels of the official Cityscapes test set are unavailable, the labeled partitions will be reorganized for local model development and evaluation.

Partition Images Purpose
Train 2,475 Model optimization
Validation 500 Hyperparameter tuning and checkpoint selection
Local Test 500 Final quantitative evaluation using the official labeled validation partition
Official Unlabeled Test 1,525 Qualitative inference only

Leakage Prevention

  • Training, validation, and local test samples will not overlap.
  • Cityscapes city and sequence partitioning will be respected.
  • Each RGB image remains paired with its corresponding mask.
  • Data augmentation will only be applied to training images.
  • A fixed random seed of 42 will be used for reproducibility.

Images will be resized to approximately 1024 × 512 pixels or randomly cropped into patches such as 512 × 512 during training to reduce computational cost.

5. Evaluation Metrics

Primary Metric — Mean Intersection over Union (mIoU)

Mean Intersection over Union measures the average overlap between predicted segmentation regions and ground-truth regions across the 19 target classes.

IoU = TP / (TP + FP + FN)

The IoU is computed for each class and then averaged to obtain mIoU.

Secondary Metrics

  • Mean Dice score
  • Per-class IoU
  • Per-class Dice score
  • Overall pixel accuracy

Per-class metrics are particularly important because the Cityscapes class distribution is strongly imbalanced.

6. Planned Methods and Architectures

6.1 Baseline — U-Net

The baseline model will be a U-Net trained from scratch.

U-Net contains an encoder that extracts increasingly abstract image features and a decoder that restores spatial resolution. Skip connections transfer feature information from encoder stages to corresponding decoder stages, helping preserve spatial details and object boundaries.

All U-Net parameters will be randomly initialized.

6.2 Pretrained Model — DeepLabV3

The pretrained model will be DeepLabV3 with a ResNet-50 backbone pretrained on ImageNet.

DeepLabV3 uses atrous convolution and Atrous Spatial Pyramid Pooling (ASPP) to capture contextual information at multiple spatial scales.

The segmentation head will be configured to predict the 19 Cityscapes evaluation classes.

6.3 Fine-tuning Strategy

The pretrained ResNet-50 backbone will initially be frozen while the segmentation head is trained.

The backbone will then be unfrozen and the full model fine-tuned using a lower learning rate for the pretrained parameters.

6.4 Planned Controlled Experiments

At least one controlled experiment will be conducted. Planned experiments include:

  1. Fine-tuning strategy: frozen encoder versus full-network fine-tuning.
  2. Loss function: Cross-Entropy loss versus Cross-Entropy + Dice loss.

For a fair comparison, the dataset split, input resolution, evaluation metrics, and random seed will remain fixed while only the selected experimental factor is changed.
